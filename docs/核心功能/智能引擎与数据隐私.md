# 智能引擎与数据隐私

## 能力与输入

智能引擎通过 Codex CLI 提供分析能力，结果供业务流程参考；实际开聊和投递仍需通过账号、额度、匹配和防重检查。

| 能力 | 输入与用途 |
| --- | --- |
| 简历画像 | 从导入简历提取正文并脱敏，生成候选人画像 |
| 检索规划 | 结合求职目标与画像组织检索 |
| 岗位评估 | 使用必要岗位信息与画像判断匹配度 |
| 消息分析与草稿 | 按授权使用相关上下文生成本地参考内容 |

## 授权与设置

入口为“系统设置 → 智能引擎”，包括服务授权、模型选择、推理强度、分析功能和数据授权。BossPilot 使用独立 Codex 目录，不复用其他客户端登录，不使用 `OPENAI_API_KEY`；退出授权会中止在途分析。

| 设置 | 数据含义 |
| --- | --- |
| 岗位匹配评估 | 开启后允许发送评估所需的岗位与画像 |
| 招聘消息分析 | 开启后允许发送分析所需的岗位与画像 |
| 允许发送招聘消息 | 单独控制招聘消息文本是否可交给 Codex，默认关闭 |

生成画像时，脱敏后的简历正文会交给 Codex。求职要求与消息中应避免加入无关敏感信息。功能授权与招聘消息授权分别生效，开启消息分析不等于自动允许发送招聘消息文本。

## 数据流向

| 数据路径 | 目的地 |
| --- | --- |
| 登录、岗位检索、会话同步、附件交换 | BOSS 平台 |
| 画像生成、检索规划、岗位与消息分析 | 按授权调用的 Codex 服务 |
| 业务状态、本地分析简历、会话与授权文件 | 本机应用数据目录 |

本地保存不代表完全离线。对外投递使用 BOSS 账号附件，与提交给 Codex 的分析正文属于不同数据路径。

## 本地存储

默认根目录为 `~/Library/Application Support/BossPilot/`。

| 路径 | 内容 |
| --- | --- |
| `state.json` | 业务状态与运行记录 |
| `Attachments/` | 本地分析简历 |
| `Sessions/` | BOSS 会话文件，另有账号独立 WebKit Profile |
| `Codex/` | Codex 独立授权与配置 |

业务状态目录与文件权限分别为 `0700`、`0600`。Cookie 保存在账号独立会话中，不写入业务状态或日志，也不访问 macOS 钥匙串。文件权限属于访问控制，不代表应用层加密。

## 备份与反馈

备份前停止任务并退出应用，避免复制写入中的状态。整个应用支持目录包含附件与授权文件，应按敏感资料保管；跨设备恢复后重新核对授权和平台会话。

反馈问题时提供必要错误信息和脱敏截图，勿上传业务状态、简历原件、Cookie、会话目录或授权目录。仓库忽略规则只能辅助排除文件，提交前仍需检查。
