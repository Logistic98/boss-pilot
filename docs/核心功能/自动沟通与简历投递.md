# 自动沟通与简历投递

## 执行范围

自动任务依次推进岗位检索、详情补全、匹配评估、预设招呼语开聊、消息同步与附件简历投递。沟通草稿仅供本地参考，不自动发送任意文字回复。手动刷新只同步数据，不触发外发。

## 启动条件与默认配置

从运行设置启动任务，需要已导入本地简历、至少一个通过登录和本人验证检查的可运行账号，且未处于风险冷却期。启用岗位检索时需保存求职条件；岗位检索与消息同步至少启用一项。简历投递依赖消息同步。

| 配置 | 默认值 | 可设置范围 |
| --- | --- | --- |
| 后台任务 | 未启动 | 手动启动或停止 |
| 岗位检索 | 开启 | 以运行设置为准 |
| 消息同步 | 开启 | 开启或关闭 |
| 自动简历投递 | 关闭 | 满足条件后开启 |
| 候选补货间隔 | 每批完成后至少 90 秒 | 按待开聊库存自动调度 |
| 消息同步间隔 | 60 分钟 | 30–180 分钟 |
| 每账号每日开聊上限 | 150 | 1–150 |
| 同账号相邻开聊间隔 | 180 秒 | 180–1800 秒 |

已有配置或历史迁移值可能与默认值不同，以应用显示为准。上限是约束，不是任务必须完成的数量；多账号共用进程级请求调度。

## 岗位检索与自动开聊

岗位详情逐条保存，后续同步复用已有信息并补齐缺失项。缺少完整描述的岗位不能自动开聊。

自动任务按待开聊候选库存补货：不足 8 个时，上一批结束至少 90 秒后继续，优先补齐已缓存岗位详情，没有可处理积压时再检索下一页；库存充足或当日开聊额度用完时暂停补货。每批最多读取 4 个详情，单个岗位读取失败后保留 15 分钟退避。

列表已有明确排除项、薪资不重合或严格限定城市不符时，不再为其读取详情；未知字段与缺少必需关键词仍留待详情核实。详情取得后立即进行本地评估，自动批次可提前结束，将已就绪的候选交给开聊流程。补货和发送仍共用原有请求限速，候选供给加速不代表实际发送量按相同比例增加。

匹配与最终发送前均检查明确的排除条件。外发前重新核对最新求职要求、账号状态、额度和防重记录，通过后使用对应 BOSS 账号的预设招呼语。

开聊尝试按身份与岗位去重核算，手动沟通和工具尝试均纳入额度；结果未知的尝试也占用额度。删除本地记录或重启不会清除限制。

## 两类简历的区别

| 简历 | 来源 | 用途 |
| --- | --- | --- |
| 本地分析简历 | 求职偏好中导入的 PDF、TXT 或 Markdown | 提取正文、生成画像与岗位筛选 |
| 对外投递附件 | 对应 BOSS 账号中唯一可用的附件简历 | 按交换条件发送给招聘方 |

投递前应在 BOSS 官方端核对附件版本。更新本地分析简历不会同步替换平台附件；缺少唯一可用附件时无法按此流程自动投递。

## 简历交换与确认

原生索要卡片与普通文字同意进入不同的交换流程。创建简历请求后可能仍需招聘方确认；明确拒绝会被过滤，需要判断的情况转为待办。

| 状态语义 | 含义与处理 |
| --- | --- |
| 请求已创建 | 已发起交换流程，可能仍待招聘方确认 |
| 处理中或待确认 | 核对平台回执与历史，不重复发送 |
| 已交换 | 平台接受附件发送，或完整历史确认附件已发出 |
| 结果未知 | 尚不能确定结果，只核对历史，不自动重发 |

此表解释业务语义，实际界面标签以当前页面为准。交换时间取发送或接受时间，不取后续查看时间。同一会话已有进行中、已确认或结果未知的投递时，不重复发送；后续处理与待确认回读分别按 3 分钟、5 分钟调度。

## 运行保护

外发前必须先成功持久化安全记录；保存失败则停止对应写入。普通状态保存、文本提取与 Codex 分析在后台执行。

明确限流、拒绝访问或安全验证会停止后台任务，持久化 24 小时风险冷却；到期后仍需检查账号并手动启动。本人验证还具有账号级暂停与复核流程。普通超时、业务拒绝不直接等同于全局风险冷却。

节奏控制与防重机制不能保证账号免受平台限制。异常恢复步骤见[使用指南与常见问题](../使用指南/使用指南与常见问题.md#常见问题)。
