# 使用指南与常见问题

## 首次配置

构建环境与启动命令见[README](../../README.md#快速开始)。应用启动后，按以下顺序配置。

### 1. 登录账号

在“账号管理”添加账号，使用 BOSS 直聘 App 扫码确认。不同账号使用独立会话，账号名称可以修改，刷新资料不会覆盖自定义名称。

### 2. 设置求职目标

在“求职偏好”导入 PDF、TXT 或 Markdown 简历，填写岗位、城市、薪资及排除条件，保存后生效。离开页面或关闭窗口时，未保存内容会触发提示。

排除条件应具体，例如不接受实习、校招或某些城市的岗位。本地简历用于生成画像；实际投递使用 BOSS 账号中的附件简历，区别见[自动沟通与简历投递](../核心功能/自动沟通与简历投递.md#两类简历的区别)。

### 3. 配置智能引擎

打开“系统设置 → 智能引擎”，完成 Codex 授权，选择模型与推理强度，核对岗位匹配评估、招聘消息分析和数据授权。详细说明见[智能引擎与数据隐私](../核心功能/智能引擎与数据隐私.md)。

### 4. 启动任务

先在 BOSS 官方端核对招呼语和附件简历，再进入“系统设置 → 运行设置”，确认消息同步、开聊节奏与简历投递配置，启动自动运行。

启动入口要求已导入本地简历、至少一个可运行的已登录账号，且不处于风险冷却中；启用岗位检索时还需保存求职条件。后台任务默认未启动，自动投递默认关闭，投递开关依赖消息同步。

## 账号与数据筛选

顶部账号菜单支持多选，启动时默认全选。列表按所选账号展示，统计仅包含已登录账号。账号筛选只改变当前展示，停止任务应使用运行设置中的停止入口。

退出账号保留本地业务数据；重新登录同一身份后恢复关联。更换身份时，重新核对该账号的招呼语、附件简历和运行配置。

## 日常操作

手动刷新只同步数据，不触发开聊或发送简历。任务按低频节奏排队，启动后可结合运行状态、岗位详情与会话状态查看进度。

岗位和消息支持多选、批量删除及右键删除，消息可批量标记已处理。删除仅影响本地记录，后续同步可能重新获取；额度和投递防重记录仍保留。

需要用户判断的消息进入待办。本人验证按官方页面提示完成，再回到应用复核；风险冷却到期后需检查账号并手动启动。具体排查见[使用指南与常见问题](使用指南与常见问题.md#常见问题)。

## 常见问题

### 运行与开聊

#### 启动后没有立即开聊

先查看运行设置的状态与提示，再依次检查登录、本人验证、本地简历、求职条件、岗位详情、匹配结果、额度和间隔。任务使用低频调度，每日上限不代表立即批量发送。完整条件见[自动沟通与简历投递](../核心功能/自动沟通与简历投递.md#启动条件与默认配置)。

#### 手动刷新后没有发送

刷新只同步数据。外发由后台任务推进，自动投递还需开启投递开关、消息同步并具备可用平台附件。

#### 是否自动回复所有消息

不自动发送任意文字回复。自动沟通使用预设招呼语开聊，消息分析和草稿用于辅助处理，需要判断的内容进入待办。

### 简历与投递

#### 招聘方会收到本地导入的简历吗

实际投递使用对应 BOSS 账号中的附件，版本需在官方端维护。见[自动沟通与简历投递](../核心功能/自动沟通与简历投递.md#两类简历的区别)。

#### 请求已创建，为什么还没有已交换

交换请求可能仍需招聘方确认。平台接受附件发送或完整历史确认已发出后，才计为已交换。见[自动沟通与简历投递](../核心功能/自动沟通与简历投递.md#简历交换与确认)。

#### 超时或结果未知后如何处理

核对平台消息历史，等待结果确认。不要通过删除记录、重新登录或手改状态触发重发，避免重复投递。

### 账号与同步

#### 同步后仍缺少旧会话

首次枚举依赖官方页面已加载的会话，好友补全接口不能替代全量列表。先在官方页面核对会话加载情况，再按应用流程刷新；本地列表不保证覆盖完整平台历史。

#### 如何恢复本人验证或风险冷却

本人验证在官方页面完成后，回到应用复核。风险冷却会持久化，当前为 24 小时；到期后检查账号，再手动启动。重启不会清除冷却。

#### 取消顶部账号勾选会停止任务吗

账号筛选只改变展示。停止任务使用运行设置中的停止入口。退出账号保留本地业务记录，但不再计入已登录账号统计。

#### 删除记录后为什么再次出现

本地删除不会撤销平台操作，后续同步可能重新获取记录。额度和投递防重记录仍保留。

### 授权与诊断

#### 其他客户端已登录 Codex，为什么还需授权

BossPilot 使用独立授权目录。在智能引擎中完成授权，检查 CLI 路径、服务状态与模型列表；需要时使用“重新检查”或“刷新模型”。

#### 本地存储是否代表完全离线

BOSS 交互与 Codex 分析仍需联网，分析按数据授权执行。数据路径与本地目录见[智能引擎与数据隐私](../核心功能/智能引擎与数据隐私.md)。

#### 构建或界面异常如何排查

核对系统、Swift 和 SDK，再选择隔离自检、预览或日志入口，见[开发构建与调试验证](../开发维护/开发构建与调试验证.md)。保存编辑内容后再运行会替换应用包的命令，界面问题无需执行正式投递诊断。
